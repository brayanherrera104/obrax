OBRAX 2.1 — PROTOTIPO SAAS

Incluye landing, DEMO, registro, login con contraseña protegida, SQLite, proyectos y APUs 2.0 persistentes por empresa.

INSTALAR:
1. Instala Python 3.10+.
2. Abre terminal en esta carpeta.
3. pip install -r requirements.txt
4. python app.py
5. Abre http://127.0.0.1:5000

DEMO: pulsa “Probar DEMO”.
CUENTA REAL: “Crear cuenta”, registra empresa, correo y contraseña; luego puedes salir y volver a entrar.

Es prototipo local. Antes de producción: HTTPS, PostgreSQL, recuperación/verificación de correo, roles, CSRF/rate limiting, copias de seguridad, pagos y auditoría.
